General Features of the Pandamonium

- Blockly UI with blocks for Pandas and Scikit Learn

The main features include:
- Use the Blockly js lib
- Make all the custom blocks and plan out what can link or match to what. Cover all Pandas and Sci-kit features
- Convert the blocks into working Python code with comments. 
- Make a playground using your playground skill. It should use pyiode and load the libs required to actually execute the DS pipeline. Should allow users to swap between block ui and code. Have examples that can be loaded. 
- There should be a compiled dist folder that the examples can use.
